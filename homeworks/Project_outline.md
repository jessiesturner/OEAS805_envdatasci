## Exploratory Data Analysis (EDA) Notebook

In the `CODE/` directory, include a Jupyter notebook performing EDA for every data type you plan to use. Pair clear visualizations with short explanatory text paragraphs addressing the following:

* **Data Description & Access**
  * Detailed description of each dataset.
  * Clear access instructions/links for external data sources, or an explicit statement if it is your own primary data.
* **Spatial & Temporal Coverage**
  * Spatial bounds and resolution for each dataset.
  * Temporal range and sampling frequency for each dataset.
* **Data Integration & Overlap**
  * Degree of spatial and temporal overlap across your different data types.
  * Compatibility and resolution alignment between datasets.
* **Visualization Guidelines**
  * Include appropriate plots and figures.
  * Ensure all figures include titles, clearly labeled axes, and units.
